# 墨迹文字识别的使用与人工校对

资料说明：本文由项目自行编写，是软件使用示例资料，不是老师发布的教材、作业要求或评分标准。具体课程要求请以教师原始通知为准。

识别前先选择文字模式。汉字模式用于中文汉字；字母／数字模式用于英文字母、阿拉伯数字及其混写。两种模式使用同一画板与上传入口。选择模式会约束解码时可接受的字符范围，但不会消除形近字误识别。O 与 0、I 与 1、b 与 6 等仍需结合原图核对。

画板上应写得清晰，给字符留出适当间距，避免把多行文字紧贴在一起。上传支持 PNG、JPEG 和 WebP；空白、损坏文件、超过图片限制的输入会被拒绝。上传图像的文字越小、背景越复杂、倾斜越严重，识别难度通常越高。

识别结果不是经过人工认证的事实。请对照原图查看错字、漏字与标点，并将修正后的内容保存到人工校对字段。原始模型输出与人工校对文字分别保存，便于追溯。置信度是模型估计，不等于该次结果的真实正确率。

整理为知识资料时，应先保存非空的人工校对文字，再勾选确认并导入。知识库保存的是用户确认的文本快照，不会自动把未经核对的 OCR 原文当成教材，也不会因一次工具读取就修改识别历史。若后续再次校对原记录，已导入的知识快照需要用户另行更新。

知识库搜索使用中文词项 BM25 词法检索，可展示匹配片段与文档来源。离线助手只做原文摘录与规则工具编排，未调用大语言模型；显式开启已配置的模型后，才会把问题、对话上下文和参考片段发送给该模型整理回答。无匹配资料时，应说明缺少依据。
