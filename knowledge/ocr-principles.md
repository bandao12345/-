# OCR、CTC 与识别结果的解释

资料说明：本文是项目自编的原理短文，用于演示本地知识库，不代表学校教材，也不是所用模型的完整技术说明。

OCR 是光学字符识别：从包含文字的图像提取字符。常见流程包括图像预处理、文本区域检测、文字识别和阅读顺序整理。干净画板与复杂场景图片可能采用不同布局路径，但都应保留原始笔迹作为核对依据。

CTC 解码把模型在多个时间位置预测的字符概率变成文字序列。它通常包含空白符，并处理相邻重复字符。字符集约束可以在解码前屏蔽当前模式不允许的字符，而不是识别之后用字典把答案替换成预设文本。被保留字符的原始概率仍需用于置信度判断。

识别存在不确定性。相似笔画、断笔、连笔、触碰、倾斜和背景干扰都可能造成混淆。一个对照样例识别成功，只证明该样例和应用路径工作，不能推导出全部真实手写输入的准确率。测试数量、场景覆盖与独立评估数据应分别说明。

预训练模型推理与训练模型是不同工作。加载预训练模型并在本机运行，不能声称重新训练了该模型；CPU 本地推理也不能作为 GPU 或 NPU 迁移已经验证的证据。代码、测试和实验报告应如实区分实际完成与尚未验证的环节。

检索增强生成将资料检索与模型生成结合。本项目的知识检索采用分块、中文单字及相邻双字词项、英文词项和 BM25 排序，没有 embedding 或向量数据库。词法检索容易解释来源，但同义改写可能漏检，字面相似也可能误检。来源片段和引用应由用户核对。
