01

我们改编了什么

原实验

在模型开发环境中完成 MNIST 数据读取、CNN 训练与测试，并介绍 GPU 到 NPU 的迁移。

沿用

单数字分类任务、MNIST 数据及卷积网络思路，保留可核验的训练和测试指标。

新增

画板与上传交互、图片预处理、HTTP 推理接口、SQLite 持久化、查询导出、人工校对及评估看板。

实际环境

本次在本机 CPU 训练和推理；未执行或声称完成云端 GPU / NPU 迁移。

02

一个请求，如何变成结果

  1. 1
    输入与校验

    画板、图片或真实测试样例；限制格式、大小与尺寸。

  2. 2
    预处理与推理

    灰度、反色判断、裁边、等比缩放与居中，送入 CNN。

  3. 3
    保存与呈现

    Flask 返回概率与预览，SQLite 保存成功记录。

  4. 4
    查询与复核

    按条件查询、查看详情、人工校对，并导出数据。

03

工程实现与使用边界

前后端与数据

原生 HTML / CSS / JavaScript + Flask API + SQLite，静态资源随项目提供，无需外部 CDN。

协作开发

由 CodeArts 开发过程与后续协作补全组成，具体贡献和验证结果以实际代码、会话及交付文档为准。

结果的可解释性

返回实际预处理图、Top 3 概率与耗时；异常输入明确报错，缺失模型不生成虚假预测。

数据与局限

识别记录保存在本机；对外开放时访问者可使用记录功能。适用于课程演示，不用于身份或高风险判断。
