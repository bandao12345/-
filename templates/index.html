    01
    实验与模型，分别来自哪里
    原实验
    华为云 ModelArts 的 MNIST CNN 数字识别与 GPU 到 NPU 迁移教程。本项目未执行云端迁移部分。
    原模型
    本机 CPU 训练的单数字 CNN、训练日志和独立测试指标保留在原版目录，可与升级版分别运行。
    OCR 引擎
    正在读取实际文字检测与识别引擎信息。
    工程扩展
    汉字 / 字母数字分模式、人工校对、资料导入与知识库、本地 BM25 检索、带引用问答、可追溯的规则工具流程，以及可选的本机或云模型生成。
    02
    一个输入，如何读成文字
    1. 1
      选择模式与校验输入
      先选汉字或字母 / 数字，再接收同一画板或图片，检查真实格式、尺寸、体积与有效内容。
    2. 2
      自动检测文字区域
      在图中定位文字区域；汉字与英文字母 / 数字分开识别，不对跨模式混写作自动判断。
    3. 3
      按所选模式识别并排序
      后端按模式约束候选字符，使用实际模型输出文字、置信度与检测框，按位置组合结果。
    4. 4
      保存、复核与导出
      SQLite 保存本次预测，人工校对独立记录，可搜索和导出。
    

    03
    工程实现与使用边界
    本机全栈应用
    HTML / CSS / JavaScript、Flask API、SQLite 与本机 OCR 推理，页面资源不依赖外部 CDN。
    真实协作过程
    CodeArts 完成原模型和初版开发，后续协作完善业务与升级；保留实际会话，不把后续扩展归为全部由 CodeArts 完成。
    适用输入
    按内容选择汉字或字母 / 数字模式，避免汉字与字母数字跨模式混写。清晰、间距合适的横排文字较适合识别；潦草、连笔、竖排、极小文字或复杂版面仍可能失败。
    保留与备份
    原单数字项目、模型与原网址独立保留。升级版采用新数据库，原版识别记录不混入本版。
