# 工程训练2方案四与本项目的对应

本项目选择方案四。课程原文允许从华为网站选择MindSpore或PyTorch实验，用CodeArts改造成全栈项目，再使用ngrok演示并制作PPT，提交GitHub链接或项目截图。

| 要求或扩展 | 已有成果与入口 |
| --- | --- |
| 华为网站实验来源 | 华为ModelArts《GPU迁移到NPU：手写数字识别》，原CNN保留在 `legacy/mnist/` |
| 全栈项目 | 根目录Flask/Waitress API、HTML/CSS/JavaScript画板与六页界面 |
| 数据库 | SQLite识别历史、人工校对、备注、筛选与导出；资料库独立持久化 |
| RAG知识库 | 资料导入、分块、中文BM25索引、来源片段、可选本机Qwen生成 |
| 工具与MCP | 有限规则工具流程、五个真实MCP工具、实际stdio连接 |
| 项目技能 | 根目录 `SKILL.md` |
| ngrok演示 | 已有实际验收；现有 `start-demo.bat` 提供独立演示库及授权入口 |
| PPT答辩 | `presentations/` 中的已有14页PPT，含备注讲稿 |
| 训练数据与模型 | 原60,000张训练图/10,000张测试图压缩包、原CNN权重与指标；新模型按清单下载 |

原单数字CNN实际完成CPU训练。没有把98.92%称为新版汉字准确率，没有把预训练OCR/Qwen称为自行训练或微调。工具助手是有限规则编排，并非通用自主智能体。没有实际部署云服务器或Docker容器，没有证书或NPU/GPU实验成功的材料。

CodeArts完成原模型、训练脚本和初版服务，后续由Codex协作完成扩展，按真实过程表述。老师的算力、Coze、MindSpore等教程属于课程参考资料，不作为本项目已完成的额外实验，也不把它们复制成项目源码。
