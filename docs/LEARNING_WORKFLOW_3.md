# 学习资料流程与验证范围

用户在同一画板选择汉字或字母数字，识别后查看原图和文字，再保存人工校对。确认后的文字可以导入资料库，或直接导入UTF-8文本、Markdown和含文本PDF。知识库按约700字符分块，利用中文单字/双字词项和BM25排序，返回原文与位置。

默认问答为明确标注的原文摘录，开启配置好的模型后才向它发送问题及片段并生成回答。当前问答以资料为依据，不保证回答所有通用问题；完整聊天历史没有持久保存。识别记录的只读查询会说明其范围，也不能推断笔迹作者身份。

模型为PP-OCRv6与可选本机Qwen，二者使用预训练权重，没有在本项目微调。人工校对单独保存，不自动训练模型。原MNIST CNN有独立训练记录和98.92%的标准测试成绩，不能混用为通用OCR成绩。

根目录SKILL说明工具流程，mcp_server.py通过stdio访问既有HTTP应用，未重复加载识别模型或另建知识库。内部规则计划最多执行四次白名单操作并展示轨迹。

2026-10-22的原开发验收摘要保留在verification_3.json。公共提交保留不依赖私人笔迹的基础测试；私人数据库、私人回归图、开发机器配置及临时运行日志不公开。ngrok历史验收不等于永久云托管，容器和云服务器尚未实际部署。
