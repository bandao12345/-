# 验收样例来源与边界

所有预期文字在运行OCR前固定。样例用于功能回归，不构成独立的识别准确率评测。

- 单数字：原项目的真实MNIST测试样例；多数字为逐字拼接。
- 字母：PaddleOCR官方文档展示的NIST SD19手写示例a至i，裁剪出a/b/c；单字母为真实手写裁剪，多字母为合成拼接。NIST原数据页：https://www.nist.gov/srd/nist-special-database-19 。
- 汉字：PaddleOCR官方文档展示的CASIA手写示例，裁剪出吧/耙/扳；单汉字为真实手写裁剪，多汉字为合成拼接。原数据出处为中科院自动化所CASIA HWDB，数据集约束以原站说明为准。
- 混合手写：由上列三类来源逐字拼接，不是自然连续书写。
- 印刷对照：本机Windows黑体生成的工程训练 ABC 2026，仅验证印刷输入流程。
- 规范笔画模拟：开发者人工定义少量折线，并在写字板上以真实pointer事件回放；不是自然手写或第三方测试集。

具体原图URL、类别与合成标记见manifest.json。来自PaddleOCR仓库的文档示例保留其Apache-2.0许可证副本PaddleOCR-LICENSE.txt；基础数据集的权利仍归原权利人，不把仓库代码许可证解释为替代原始数据条款。样例预期由目视核对而非原始机器标注文件，遇到歧义应人工复核。

## 人工转写修订

初看98像素高原图时，把CASIA第四、第五字人工误写为把、板。后将原图等比放大独立重看，第四字左旁含耒的多横与撇捺，第五字左旁为扌而非木，故转写订为耙、扳。manifest保留initial_manual_transcription，不改动图像像素，不把OCR模型预测用作机器真值。原站示例没有逐字标签，本小样依旧只作为人工核对的功能验收，不能据此汇报通用手写准确率。
